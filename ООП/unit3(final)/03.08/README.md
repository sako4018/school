# Task_03_08

Конзолно приложение на C# (.NET 8) за задача 03.08 „Служители и студенти“ от unit 3: шаблонни типове (ООП).

## Задание

Интерфейси `IPerson` и `IEmployee`, класове `HeadTeacher`, `Teacher`, `Staff`, `Student` и колекция `Persons<T>`.

Засега проектът е начална заготовка и извежда само `Hello World!`. Пълното условие е в Classroom, „final tasks(unit 3)“.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/unit3(final)/03.08"
dotnet run
```

## Структура

- `Task_03_08.csproj` – проектният файл (.NET 8, конзолно приложение)
- `Program.cs` – входна точка с метода `Main`
