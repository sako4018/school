# Task_03_10

Конзолно приложение на C# (.NET 8) за задача 03.10 „IVehicle“ от unit 3: шаблонни типове (ООП).

## Задание

Интерфейс `IVehicle`, класове `Bicycle` и `Car` с промяна на скоростта и колекция `Generic<T>`.

Засега проектът е начална заготовка и извежда само `Hello World!`. Пълното условие е в Classroom, „final tasks(unit 3)“.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/unit3(final)/03.10"
dotnet run
```

## Структура

- `Task_03_10.csproj` – проектният файл (.NET 8, конзолно приложение)
- `Program.cs` – входна точка с метода `Main`
