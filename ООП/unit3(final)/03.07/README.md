# Task_03_07

Конзолно приложение на C# (.NET 8) за задача 03.07 „Самолетни полети“ от unit 3: шаблонни типове (ООП).

## Задание

Интерфейс `IAirplane_flight`, клас `Person` и колекции `Paris<T>` и `Milano<T>` за пътници според дестинацията.

Програмата добавя пътници в `Paris<Person>` и `Milano<Person>` според дестинацията, отхвърля непозната дестинация и извежда пътниците и броя им. Условието е в Classroom, „final tasks(unit 3)“.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/unit3(final)/03.07"
dotnet run
```

## Структура

- `Task_03_07.csproj` – проектният файл (.NET 8, конзолно приложение)
- `Program.cs` – входна точка с метода `Main`
