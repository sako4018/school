# Task_03_09

Конзолно приложение на C# (.NET 8) за задача 03.09 „Банка“ от unit 3: шаблонни типове (ООП).

## Задание

Интерфейс `Bank_Account`, клас `Person` с депозит и теглене и колекция `Generic<T>` за клиентите.

Засега проектът е начална заготовка и извежда само `Hello World!`. Пълното условие е в Classroom, „final tasks(unit 3)“.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/unit3(final)/03.09"
dotnet run
```

## Структура

- `Task_03_09.csproj` – проектният файл (.NET 8, конзолно приложение)
- `Program.cs` – входна точка с метода `Main`
