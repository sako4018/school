# Fragrance

Конзолно приложение на C# (.NET 8) за часовете по ООП.

## Как се пуска

От папката на проекта:

```bash
cd "$HOME/Desktop/Developer/училище/ООП/Fragrance"
dotnet run
```

## Структура

```
Fragrance/
├── Fragrance.csproj   # настройки на проекта (net8.0, Exe)
├── Program.cs         # входна точка: клас Program с метод Main
└── README.md
```

Папките `bin/` и `obj/` се създават при build и не се качват в git.
