# Task_03_04

Конзолно приложение на C# (.NET 8) за задача 03.04 „Ферма за животни“: шаблонни типове (ООП).

## Задание

Абстрактен клас `Animal` с `Count`, `Name` и `FoodGrams`, наследници `Bird`, `Cow`, `Rabbit` и колекция `Animal_Farms<T> where T : Animal`. Програмата чете броя птици, крави и зайци (с `int.TryParse`, отхвърля отрицателни и нечислови стойности) и извежда дневната храна за всеки вид и общата сума в грамове. Условието е в Classroom, „Generics tasks“.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/generic/03.04"
dotnet run
```

Пример: вход `2`, `3`, `4` дава `Bird: 907 g`, `Cow: 6000 g`, `Rabbit: 400 g`, `Total: 7307 g`.
