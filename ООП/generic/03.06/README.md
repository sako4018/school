# Task_03_06

Конзолно приложение на C# (.NET 8) за задача 03.06 „Упражнение за шаблони“: шаблонни типове (ООП).

## Задание

Интерфейси `IAnimal`, `IMammal` и `Animal_food`, класове `Bird` и `Cow` и колекция `Generic_class<T>` с индексатор само за четене. Всички обекти се пазят в `Generic_class<IAnimal>` и се обхождат с `for`. Видът се разпознава с `is Bird` и `is Cow`, а `IsBabyMammal` и `Animal_food` се четат само след проверка с `is`. Условието е в Classroom, „Generics tasks“.

Програмата няма вход. Показва и празна колекция, и невалиден индекс.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/generic/03.06"
dotnet run
```

## Структура

- `Task_03_06.csproj` – проектният файл (.NET 8, конзолно приложение)
- `Program.cs` – интерфейсите, класовете и входната точка `Main`
