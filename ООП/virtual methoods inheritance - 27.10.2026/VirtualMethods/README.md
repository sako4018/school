# VirtualMethods

Училищен проект по ООП (27.10.2026): виртуални методи и наследяване в C#.

## Как се пуска

```bash
cd "VirtualMethods"
dotnet run
```

Изисква .NET 8 SDK.

## Структура

```
VirtualMethods/
├── VirtualMethods.csproj   # настройки на проекта (net8.0, конзолно приложение)
├── Program.cs              # входна точка (Main)
└── README.md
```
