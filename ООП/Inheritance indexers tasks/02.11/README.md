# Task_02_11

Конзолно приложение на C# (.NET 8) за задача 02.11 „Библиотека“: наследяване (ООП).

## Задание

`Book` с наследниците `Book_Romance`, `Book_Crime`, `Book_Science`, статичен списък `AvailableBooks` и `Reader` с `StudentReader` и `RegularReader`. Заемането на вече взета книга връща `false`, а съобщенията на читателите се извеждат само след успешно заемане. Условието е в Classroom, „Задачки закачки“.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/Inheritance indexers tasks/02.11"
dotnet run
```

## Структура

- `Task_02_11.csproj` – проектният файл (.NET 8, конзолно приложение)
- `Program.cs` – класовете и входната точка `Main`
