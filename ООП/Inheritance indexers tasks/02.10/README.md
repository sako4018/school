# Task_02_10

Конзолно приложение на C# (.NET 8) за задача 02.10 „Магазин за авточасти“: наследяване (ООП).

## Задание

`Manufacturer`, `Car` (с референция към производителя), `Part` (с референция към автомобила) и наследниците `EnginePart`, `ChassisPart`, `BodyPart`. Програмата търси по производител (Renault) и по категория (Engine). Без съвпадение извежда „Няма намерени части“. Условието е в Classroom, „Задачки закачки“.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/Inheritance indexers tasks/02.10"
dotnet run
```

## Структура

- `Task_02_10.csproj` – проектният файл (.NET 8, конзолно приложение)
- `Program.cs` – класовете и входната точка `Main`
