# Task_02_15

Конзолно приложение на C# (.NET 8) за задача 02.15 „Food“: наследяване (ООП).

## Задание

`FoodItem` с наследниците `MainCourse` (веган -10%), `Dessert` (без захар +15%) и `Drink` (алкохолна +20%), `Order` и меню в `Dictionary`. Потребителят въвежда име и избира ястия до думата „стоп“, после се извеждат поръчката и общата сума. Условието е в Classroom, „Задачки закачки“.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/Inheritance indexers tasks/02.15"
dotnet run
```

## Структура

- `Task_02_15.csproj` – проектният файл (.NET 8, конзолно приложение)
- `Program.cs` – класовете и входната точка `Main`
