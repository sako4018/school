# Task_02_12

Конзолно приложение на C# (.NET 8) за задача 02.12 „Театър“: наследяване (ООП).

## Задание

`Ticket` и `Discount_ticket` с 50% отстъпка при възраст под 20 или над 60. Програмата пита за представление и вид билет (`regular` или `discount`), за намаление пита за име и години, и спира с `exit`. Условието е в Classroom, „Задачки закачки“.

## Как се пуска

```bash
cd "$HOME/Desktop/Developer/училище/ООП/Inheritance indexers tasks/02.12"
dotnet run
```

## Структура

- `Task_02_12.csproj` – проектният файл (.NET 8, конзолно приложение)
- `Program.cs` – класовете и входната точка `Main`
