# Cinema booking

Тестване на резервации за кино (C#, .NET 10, NUnit) — задача „03.11 Тестване на резервации за кино“.

## Какво има
- `MovieTicketBooking.cs` — оригиналният клас с оставени грешки и двата нови метода `CancelBooking` и `GetTotalSales`.
- `MovieTicketBookingTests.cs` — unit тестове (NUnit).
- `Program.cs` — конзолно приложение с меню (резервация, отказ, цена, свободни места, продажби).

## Намерени грешки (не са поправени, както е по условие; описани са в unit тестовете)
1. Няма проверка за празно/null име на филм.
2. Няма проверка за отрицателна цена.
3. `isPremium` не се използва в `CalculatePrice`.
4. Цената се закръгля до 1 знак вместо до 2.
5. `GetAvailableSeats` не изважда резервираните места.
6. `BookedSeats` е публичен списък и може да се променя отвън.

Тестовете за тези 6 грешки **падат нарочно** — така се вижда, че грешките съществуват.

## Приети допускания (условието не ги уточнява)
- Premium билетът трябва да струва повече от обикновения (колко точно — не е определено).
- Цената се закръгля до 2 знака, 12.345 -> 12.35.
- `GetTotalSales` = брой резервирани места x базова цена; откази не се броят.
- Отказ на невалидно място -> `ArgumentException`; на нерезервирано -> `InvalidOperationException`.

## Как се пуска
```bash
cd "Cinema booking"
dotnet test   # тестове
dotnet run    # конзолното приложение
```
Резултат от тестовете: 17 минават, 6 падат (грешките от оригиналния код).
