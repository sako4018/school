# Shop

ASP.NET Core MVC проект (.NET 8) за задачата „магазин“ (shop-02.12). Създаден е като шаблона „ASP.NET Core Web App (Model-View-Controller)“ във Visual Studio.

## Как се пуска

```bash
cd "shop-02.12/Shop"
dotnet run
```

След това отвори адреса, който се показва в терминала (напр. `http://localhost:5xxx`).

Във VS Code: `code "shop-02.12"`

## Структура

- `Shop.sln` – solution файлът
- `Shop/Controllers/` – контролерите (`HomeController`)
- `Shop/Models/` – моделите
- `Shop/Views/` – изгледите (Razor `.cshtml`)
- `Shop/wwwroot/` – статични файлове (CSS, JS, Bootstrap)
- `Shop/Program.cs` – стартиране и настройка на приложението
