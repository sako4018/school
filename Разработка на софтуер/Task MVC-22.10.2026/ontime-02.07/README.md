# OnTime

ASP.NET Core MVC проект (.NET 8) за задачата „OnTime“ (ontime-02.07). Създаден е като шаблона „ASP.NET Core Web App (Model-View-Controller)“ във Visual Studio.

## Как се пуска

```bash
cd "ontime-02.07/OnTime"
dotnet run
```

След това отвори адреса, който се показва в терминала (напр. `http://localhost:5xxx`).

Във VS Code: `code "ontime-02.07"`

## Структура

- `OnTime.sln` – solution файлът
- `OnTime/Controllers/` – контролерите (`HomeController`)
- `OnTime/Models/` – моделите
- `OnTime/Views/` – изгледите (Razor `.cshtml`)
- `OnTime/wwwroot/` – статични файлове (CSS, JS, Bootstrap)
- `OnTime/Program.cs` – стартиране и настройка на приложението
