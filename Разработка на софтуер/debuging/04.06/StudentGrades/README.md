# StudentGrades (04.06)

Конзолно приложение (C#, .NET 8) за упражнение по дебъгване: въвеждане на брой и стойности на оценки и изчисляване на средната оценка.

Началният код е от задачата и съдържа умишлени грешки, които трябва да се намерят и поправят. До всеки променен ред се добавя коментар.

## Как се пуска

```bash
cd "StudentGrades"
dotnet run
```
