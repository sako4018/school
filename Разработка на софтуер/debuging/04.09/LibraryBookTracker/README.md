# LibraryBookTracker (04.09)

Конзолно приложение (C#, .NET 8) за упражнение по дебъгване: добавяне, заемане и връщане на книги, показване на наличните и сортиране.

Началният код е от задачата и съдържа умишлени грешки, които трябва да се намерят и поправят. До всеки променен ред се добавя коментар.

## Как се пуска

```bash
cd "LibraryBookTracker"
dotnet run
```
