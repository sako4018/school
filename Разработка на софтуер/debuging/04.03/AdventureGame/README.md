# AdventureGame (04.03)

Конзолно приложение (C#, .NET 8) за упражнение по дебъгване: игра на карта 5x5 с команди up, down, left, right и quit.

Началният код е от задачата и съдържа умишлени грешки, които трябва да се намерят и поправят. До всеки променен ред се добавя коментар.

## Как се пуска

```bash
cd "AdventureGame"
dotnet run
```
