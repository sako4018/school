# BankingSystem (04.04)

Конзолно приложение (C#, .NET 8) за упражнение по дебъгване: проста банкова система с команди deposit, withdraw, balance и quit.

Началният код е от задачата и съдържа умишлени грешки, които трябва да се намерят и поправят. До всеки променен ред се добавя коментар.

## Как се пуска

```bash
cd "BankingSystem"
dotnet run
```
