# Scoreboard (04.07)

Конзолно приложение (C#, .NET 8) за упражнение по дебъгване: класиране на играчи с команди add, show, top, search, average и quit.

Началният код е от задачата и съдържа умишлени грешки, които трябва да се намерят и поправят. До всеки променен ред се добавя коментар.

## Как се пуска

```bash
cd "Scoreboard"
dotnet run
```
