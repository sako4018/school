# InventoryManager

Конзолно приложение (C#, .NET 8) за упражнение по дебъгване. Програмата управлява прост склад: добавя продукти, премахва продукти и ги показва.

Началният код съдържа умишлени грешки, които трябва да се намерят и поправят.

## Как се пуска

```bash
cd "InventoryManager"
dotnet run
```

## Структура

```
InventoryManager/
├── InventoryManager.csproj   # настройки на проекта (net8.0)
├── Program.cs                # класовете InventoryItem, InventoryManager и Program
└── README.md
```
