# SwimmingPool

ASP.NET Core MVC проект (.NET 8) за задачата „плувен басейн“ (swimingpool-02.14). Създаден е като шаблона „ASP.NET Core Web App (Model-View-Controller)“ във Visual Studio.

## Как се пуска

```bash
cd "swimingpool-02.14/SwimmingPool"
dotnet run
```

След това отвори адреса, който се показва в терминала (напр. `http://localhost:5xxx`).

Във VS Code: `code "swimingpool-02.14"`

## Структура

- `SwimmingPool.sln` – solution файлът
- `SwimmingPool/Controllers/` – контролерите (`HomeController`)
- `SwimmingPool/Models/` – моделите
- `SwimmingPool/Views/` – изгледите (Razor `.cshtml`)
- `SwimmingPool/wwwroot/` – статични файлове (CSS, JS, Bootstrap)
- `SwimmingPool/Program.cs` – стартиране и настройка на приложението
