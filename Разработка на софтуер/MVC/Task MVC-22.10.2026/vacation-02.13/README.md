# Vacation

ASP.NET Core MVC проект (.NET 8) за задачата „почивка“ (vacation-02.13). Създаден е като шаблона „ASP.NET Core Web App (Model-View-Controller)“ във Visual Studio.

## Как се пуска

```bash
cd "vacation-02.13/Vacation"
dotnet run
```

След това отвори адреса, който се показва в терминала (напр. `http://localhost:5xxx`).

Във VS Code: `code "vacation-02.13"`

## Структура

- `Vacation.sln` – solution файлът
- `Vacation/Controllers/` – контролерите (`HomeController`)
- `Vacation/Models/` – моделите
- `Vacation/Views/` – изгледите (Razor `.cshtml`)
- `Vacation/wwwroot/` – статични файлове (CSS, JS, Bootstrap)
- `Vacation/Program.cs` – стартиране и настройка на приложението
