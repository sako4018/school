# Cinema

ASP.NET Core MVC проект (.NET 8) за задачата „кино“ (cinema-02.11). Създаден е като шаблона „ASP.NET Core Web App (Model-View-Controller)“ във Visual Studio.

## Как се пуска

```bash
cd "cinema-02.11/Cinema"
dotnet run
```

След това отвори адреса, който се показва в терминала (напр. `http://localhost:5xxx`).

Във VS Code: `code "cinema-02.11"`

## Структура

- `Cinema.sln` – solution файлът
- `Cinema/Controllers/` – контролерите (`HomeController`)
- `Cinema/Models/` – моделите
- `Cinema/Views/` – изгледите (Razor `.cshtml`)
- `Cinema/wwwroot/` – статични файлове (CSS, JS, Bootstrap)
- `Cinema/Program.cs` – стартиране и настройка на приложението
