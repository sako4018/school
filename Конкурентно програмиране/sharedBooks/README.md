# SharedBooks

Конзолно приложение на C# (.NET 8) за предмета „Конкурентно програмиране“.

## Как се пуска

```bash
cd "~/Desktop/Developer/училище/Конкурентно програмиране/sharedBooks"
dotnet run
```

## Структура

- `SharedBooks.csproj` – настройки на проекта (`net8.0`, конзолно приложение)
- `Program.cs` – входна точка (`Main`)
