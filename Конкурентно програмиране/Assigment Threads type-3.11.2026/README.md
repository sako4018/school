# AssigmentThreadsType

Конзолно приложение на C# (.NET 8) за задачата по Конкурентно програмиране за нишки (Threads) от 3.11.2026.

## Какво прави

- **Foreground нишка** (`ForegroundNames`) – изписва 10 имена, по едно на всеки 500 ms.
- **Background нишка** (`BackgroundVowels`) – проверява всяко име дали започва с гласна (`А, Е, И, О, У, Ъ, Ю, Я` или `A, E, I, O, U`). Ако започва с гласна, изписва съобщение с името на foreground нишката.

Background нишката тръгва 250 ms по-късно, затова всяко съобщение излиза веднага след своето име. Тя приключва преди foreground нишката, понеже една background нишка спира, щом приключи последната foreground нишка.

## Как се пуска

```bash
cd "Конкурентно програмиране/Assigment Threads type-3.11.2026"
dotnet run
```
