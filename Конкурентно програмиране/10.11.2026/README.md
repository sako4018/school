# Банкова сметка с нишки

Конзолно приложение на C#, което симулира клиент и банков служител, работещи едновременно с една обща банкова сметка.

- Началният баланс е 1000 лв.
- **Клиентът** (една нишка) тегли 300 лв. три пъти. Ако парите не стигат, се извежда „Недостатъчен баланс“.
- **Служителят** (друга нишка) депозира 200 лв. три пъти.
- След всяка операция се извежда новият баланс.
- `lock` пази баланса, за да не го променят двете нишки едновременно.

## Пускане

```bash
cd "Конкурентно програмиране/10.11.2026"
dotnet run
```

## Примерен изход

Редът на операциите може да е различен при всяко пускане, защото нишките работят едновременно.

```
Теглене: -300 лв. Нов баланс: 700 лв.
Депозит: +200 лв. Нов баланс: 900 лв.
Теглене: -300 лв. Нов баланс: 600 лв.
Депозит: +200 лв. Нов баланс: 800 лв.
Теглене: -300 лв. Нов баланс: 500 лв.
Депозит: +200 лв. Нов баланс: 700 лв.
Краен баланс: 700 лв.
```
